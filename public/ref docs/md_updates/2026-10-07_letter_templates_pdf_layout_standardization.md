# Letter Templates — PDF Layout Standardization & System Unification

**Date:** 2026-10-07  
**Module:** Document Management → Letter Templates  
**Audience:** Frontend / API consumers / Design System / Quality Assurance  
**Endpoints touched:** None (visual layout & styling standardization only).  
**Frontend action:** None. Dynamic data fields and placeholders remain 100% backward-compatible.

---

## 1. Executive Summary

A comprehensive design review and standardization of all letter and document templates in `src/modules/document/letter-templates/` was conducted to establish a unified, client-ready document design system.

The previous state exhibited visual inconsistencies across templates:
- **Disparate Page Framing:** 5 certificate templates used an artificial outer double border (`.page.certificate:has(.letterhead)::after`), clashing with letterhead logos, contact strips, and footers, whereas other templates used modern borderless letterhead pages.
- **Vertical Spacing & Page Break Instability:** Overly loose vertical margins and component paddings frequently pushed signature panels, company seals, or footers onto a trailing page alone (causing orphaned signatures on page 2 while page 1 had blank space).
- **Inconsistent Section Titles & Hierarchy:** Section title patterns varied across letters, with some templates missing titles above key fact grids.
- **Misaligned Pair Progression:** Date and designation progression chevrons occasionally wrapped across rows into unassociated columns.

Using **`promotion_letter`** as the gold standard reference, the entire template family was unified and stabilized.

---

## 2. Key Enhancements & Standardizations

### 2.1 Unified Page Layout & Outer Border Removal
- **Standard `.page` Container:** Removed the `.page.certificate` double outer border frame across all templates (`experience_letter`, `bonafide_letter`, `internship_certificate`, `noc`, `salary_certificate`). All letters now share the clean, modern letterhead layout with bookend rules:
  - 2px solid `--primary-ink` bookend rule beneath the letterhead.
  - 2px solid `--primary-ink` bookend rule above the footer.
- **Internal Certificate Styling:** Preserved internal certificate centerpiece styling (`.card.cert-card`) for `internship_certificate` while maintaining the standard page container.

### 2.2 Vertical Rhythm & Overflow Optimization
- **Optimized Page Padding:** Adjusted `.page` padding to `13mm 18mm 12mm 18mm` (recovering ~20px of printable height per page while retaining 18mm print margins).
- **Proportional Component Metrics:** Tightened vertical rhythm across headers, meta strips, fact grids, cards, callouts, and table cells (saving 80–120px vertically).
- **Signature & Footer Clearance:** Reduced signature image and blank space height to a standardized 44px (from 52px) and balanced signature line margins. Single-page documents comfortably fit on page 1 without risk of overflowing.

### 2.3 Page-Break Integrity & Anti-Orphan Guards
- **Anti-Orphan Rules:** Configured print breaks so Chromium never strands signatures or footers alone on a new page:
  - The last body element/section travels with the signature panel if a page break occurs.
  - `page-break-inside: avoid` maintained across `.signature-block`, `.totals-row`, `tr`, `.card`, `.callout`, `.amount-hero`, `.sign-row`, `.fact-grid`, `.timeline-item`, and `.footer`.
  - `page-break-after: avoid` enforced on `.section-title`.

### 2.4 Consistent Section Hierarchy & Fact Grids
- **Standardized Section Titles:** Added uppercase tracked section headers (`.section-title` with `::after` hairline rule) across templates (e.g., `Appointment Overview`, `Offer Overview`, `Notice Details`, `Employee Details`, `Settlement Overview`).
- **Standardized Salutation Flow:** Ensured `Dear {{employee_name}},` or `To Whom It May Concern,` consistently opens the letter body before overview grids.
- **Aligned Progression Indicators:** Structured paired fact-grid items (e.g., Date of Joining → Last Working Day in `experience_letter` and `relieving_letter`) to sit side-by-side on the same row with CSS border chevrons.
