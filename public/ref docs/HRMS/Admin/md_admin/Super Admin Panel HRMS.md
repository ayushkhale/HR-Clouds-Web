HRMS Super Admin Panel – Access Management (For SaaS Owner) 

# 1. Dashboard (Overview) 

- Total Clients Onboarded 

- Active vs Inactive Clients 

- Pending Admin Access Requests 

- Recent Activity Logs 

- System Health & Usage Metrics 

# 2. Client Management 

# → View All Clients 

- Company Name 

- Contact Person 

- Subscription Plan 

- Active Admins 

- Status (Active / Suspended / Pending Setup) 

- Actions: View, Edit, Suspend, Delete 

# → Add New Client 

- Company Name 

- Company Email 

- Industry Type 

- Subscription Plan (Free / Standard / Enterprise) 

- Number of Employees (for billing or limits) 

- Setup Primary Admin: 

# `o` Full Name 

- Email 

- Phone 

- Role: Client Admin, HR, Manager, Read Only 

- Temporary Password / Send Invite Link 

# 3. Admin Access Control 

# → Assign Admin Access 

- Select Client Company 

- Add New Admin: 

   - Name 

   - Email 

   - Designation 

   - Role Permissions: Full, HR only, Payroll only, Recruitment only 

   - Status: Active / Inactive 

   - Two-Factor Auth Enable (Yes/No) 

   - IP Whitelist (optional) 

# → View Admins (By Client) 

- Filter by Company / Role / Status 

- Revoke Access 

- Reset Password 

- Impersonate (view as) 

# 4. Permissions & Roles Management 

- Define Custom Roles 

- Role Templates: 

   - Super Admin 

   - HR Manager 

   - Recruiter 

   - Finance / Payroll 

   - Viewer 

- Set Access Rights (Module-wise permissions) 

# 5. Logs & Audit Trail 

- Access Logs (Who logged in, When, IP) 

- Activity Logs (Who did what: created, updated, deleted) 

- Failed Login Attempts 

- System Notifications / Warnings 

# 6. Communication Settings 

- Send Welcome Email to Client Admin 

- Configure Notification Templates 

   - Invite Email 

   - Password Reset 

   - Access Revoked 

- Enable/Disable Email or SMS for specific actions 

# 7. Support & Client Interaction 

- Ticket Management for Client Issues 

- Assign Support Rep 

- Chat History / Notes 

# 8. Settings 

- Branding Options for Client Panel (Logo, Theme, Subdomain) 

- License Expiry & Renewal Settings 

- Feature Toggles (enable/disable modules per client) 

- Data Retention & Export Options
