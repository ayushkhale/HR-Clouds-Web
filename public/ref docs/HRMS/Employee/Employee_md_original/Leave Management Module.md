Leave Management Module – Features & Functionalities

### 1. Apply for Leave

- Employees can apply for various types of leave such as:
  - Casual Leave (CL)
  - Sick Leave (SL)
  - Paid Leave (PL) / Earned Leave (EL)
  - Maternity/Paternity Leave
  - Compensatory Off
  - Work From Home (WFH)
- Upload supporting documents (if required, e.g., medical certificate).
- Option to select full day, half day, or hourly leave.
- Real-time preview of leave balance before applying.

### 2. Leave Balance Tracking

- View real-time leave balance for each leave type.
- Track carry-forward leaves and lapsed leaves.
- Auto-update of balance after leave approval or rejection.
- Set visibility rules for HR to manage leave encashment, pending leaves, etc.

### 3. Leave Approval Workflow

- Multi-level configurable approval workflow:
  - Team Lead → Department Head → HR (as per policy)
- Approvers can view leave history, workload impact, and suggest alternatives.
- Instant notification and alert to employee post approval/rejection.

### 4. Leave History Dashboard

- Track all applied leaves with status: Approved / Pending / Rejected / Cancelled.
- Export leave history for any date range.
- Integrated remarks section for each approval decision.

### 5. Holiday Calendar Integration

- Company-wide and region-specific holiday calendar synced with the system.
- Auto-rejection of leave if overlapping with non-working days (optional setting).
- Option for HR to announce new holidays or restricted holidays.

### 6. Policy Enforcement & Auto Rules

- Leave module follows company-defined policies:
  - Max leaves per month/year
  - Minimum notice period
  - Sandwich rule (if applicable)
- Late application penalties or blocked periods auto-enforced.
- System-based leave eligibility checker.

### 7. Notifications & Alerts

- Email, SMS, or system alerts for:
  - Leave application submission
  - Approval/rejection notifications
  - Reminder for unused leaves
- Alerts to manager if team member applies for long leave.
