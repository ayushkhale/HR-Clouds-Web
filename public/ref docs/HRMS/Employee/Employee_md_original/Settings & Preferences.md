# Settings & Preferences

The Settings & Preferences section within the Employee Panel of the HRMS platform
empowers employees with control over their work environment, communication
preferences, and accessibility needs. This section is designed to enhance user
personalization, increase engagement, and support diverse workforce requirements.

### 1. Manage Notification Preferences

Stay in control of how and when you receive important updates from the organization.
## Key Functionalities

- Email Alerts: Enable or disable email notifications for attendance, approvals,

announcements, and payroll updates.
- SMS Notifications: Manage SMS alerts for urgent updates like shift changes, leave

approvals, or emergency communications.
- Push Notifications: Configure in-app or mobile push notifications for real-time

updates.
- Category-wise Preference: Choose notification settings by category (HR, Payroll,

Leave, Events).
- Do Not Disturb Mode: Set specific hours to mute non-essential alerts.

### 2. Set Working Hours, Shift Preferences, and Remote Work Status

Define your availability and preferences to help managers plan and schedule efficiently.
## Key Functionalities

- Preferred Working Hours: Set your ideal start and end time for regular working

days.
- Shift Preferences: Select your preferred shift (morning, evening, night), with
  - tional auto-allocation settings.
- Remote Work Status:
  - Mark availability for work-from-home days.
  - Set hybrid/in-office schedules.
  - Update real-time remote status (available/busy/offline).
- Geo-tagging for Remote Workers: Optional GPS tagging for remote check-ins and

location compliance.

### 3. Multi-language and Accessibility Settings

Create an inclusive experience tailored to individual employee needs.
## Key Functionalities

- Language Selection: Choose from multiple supported languages for the portal

interface.
- Text Size & Display Settings: Adjust font size, contrast mode, and brightness

preferences for comfortable viewing.
- Screen Reader Compatibility: Enable accessibility support for visually impaired

users.
- Keyboard Navigation Mode: Activate keyboard-only navigation for improved

accessibility.
- Color Blind Mode: Toggle visual settings optimized for different types of color vision

deficiencies.
Benefits:
- Personalizes user experience for higher satisfaction.
- Improves productivity through efficient schedule alignment.
- Enhances compliance with labor policies and remote work tracking.
- Promotes inclusivity and accessibility for all employees.
