# Helpdesk / Support Tickets

## Overview

The Helpdesk / Support Tickets module within the HRMS Employee Panel acts as a
centralized platform for employees to raise and manage queries or service requests related
to HR, IT, and Admin departments. It ensures faster resolution, better accountability, and
transparent tracking.
## Key Functionalities

### 1. Service Request Submission

- Employees can raise support tickets directly from their dashboard.
- Selectable categories: HR, IT, Admin, Payroll, Facilities, etc.
- Multiple request types like ID card issuance, hardware problems, leave disputes,

reimbursement delays, etc.
- Option to add attachments, screenshots, or documents for better context.

### 2. Ticket Categorization & Prioritization

- Automated or manual categorization of issues for better queue management.
- Priority levels: Low, Medium, High, Critical.
- Auto-routing to concerned department/team based on issue type.

### 3. Real-Time Ticket Tracking

- Dashboard showing ticket status: Open, In Progress, Resolved, Closed.
- Ticket history with all communication logs visible.
- Option to add follow-up comments or additional information.

### 4. Communication with Support Teams

- In-built messaging/chat interface within each ticket.
- Email and in-app notifications on status updates.
- Escalation options if SLA is breached or no response within time frame.

### 5. SLA Tracking & Reporting

- Pre-defined SLA (Service Level Agreements) for different types of queries.
- Auto-escalation alerts if tickets cross SLA timelines.
- SLA compliance report for support team performance evaluation.

### 6. Feedback & Ticket Closure

- Employees can rate the resolution quality.
- Mandatory feedback before closing critical/high-priority tickets.
- Reopen option available if issue persists post-resolution.

### 7. Analytics & Reports

- Department-wise ticket summary.
- Average resolution time.
- Number of tickets raised/resolved per month.
