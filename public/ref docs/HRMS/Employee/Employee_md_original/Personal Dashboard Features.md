# Personal Dashboard Features

The Personal Dashboard is a user-focused, customizable area for every employee to
monitor real-time data and manage daily work operations quickly.
Features:

### 1. Quick Overview Section

  - Today’s attendance status
  - Leave balance
  - Upcoming holidays
  - Pending tasks and deadlines

### 2. Real-Time Notifications & Announcements

  - Important HR announcements
  - Birthday and work anniversary wishes
  - Policy updates and reminders

### 3. Customizable Widgets

  - Drag-and-drop layout of most-used modules (e.g., tasks, attendance,

payroll).
  - Dark/light mode or theme switch.
  - Widget visibility based on preference.

### 4. Calendar View

  - Integration of task deadlines, holidays, training schedules.
  - Meeting/event sync (optional with Outlook or Google Calendar).

### 5. Personalized Greetings and Stats

  - Dynamic welcome message
  - Motivational quote or tip of the day
  - Stats on weekly productivity or goals
