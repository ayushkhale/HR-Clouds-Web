# **HRClouds Manager Panel – Dashboard Overview** 

# **1. Dashboard Overview** 

This is the central screen managers see immediately after logging in. It's designed for clarity, visual appeal, and quick access to essential metrics and actions. 

- **Top KPI Tiles** 

   - **Headcount** – Displays the current total number of employees with trend indicators (↑/↓) compared with the previous period. 

   - **Attrition Rate** – Monthly/year-to-date percentage of employee exits, with trend arrows and comparisons to company averages. 

   - **Attendance Summary** – Shows today's present vs. absent count, along with average monthly attendance percentage. 

- **Visualizations** 

   - **Headcount Trend Chart** – A line chart showcasing the employee count evolution over the last 12 months. 

   - **Attrition Breakdown** – A bar chart comparing voluntary and involuntary departures by department. 

   - **Attendance Heatmap** – Daily attendance mapped over the past 30 days for insights into seasonal patterns. 

These align with best practices in HR dashboards, blending workforce metrics, turnover rates, and absenteeism into a cohesive, actionable view

# **5. Interactions & Responsiveness** 

- **Tile Drill-down** : Click on any KPI tile to navigate to a detailed page (e.g., Headcount → department-wise breakdown). 

- **Chart Filters** : Allow filtering metrics by date range, department, or location. 

- **Dismissible Alerts** : Managers can acknowledge alerts to clear them from the list. 

- **Responsive Design** : Layout adapts gracefully between large desktop and tablet/mobile views, maintaining usability on smaller screens. 

# **6. Data Sources & Refresh** 

- **Real-Time & Batch Updates** : Attendance via live punch-in data; headcount and attrition updated daily. 

- **Configurable Thresholds** : HR admins set alert thresholds (e.g., alert when attendance drops below 85%). 

- **Secure Access** : Only manager-level users can view KPIs for their own department/team.
